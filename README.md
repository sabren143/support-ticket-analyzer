# Support Ticket Analyzer

Hi! I'm **Sabrin Khatib**, and this is my solution for the **Junior Full Stack Home Assignment** — specifically, **Option 1: Support Ticket Analyzer**.

This command-line tool is built in Python and helps analyze support tickets by:
- Categorizing them based on common keywords
- Displaying a summary of categories
- Showing tickets created before a user-specified date

---

## Features

- Reads and parses a JSON file of support tickets
- Categorizes tickets by keywords (e.g., login, bug, payment)
- Prints a summary report with counts per category
- Prompts the user for a date and lists older tickets

---

## Tech Used

- Language: Python 3
- Libraries: Only Python standard library (no external dependencies)
